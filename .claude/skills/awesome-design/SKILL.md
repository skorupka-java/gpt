# Awesome Design (VoltAgent/awesome-design-md)

Kolekcja analiz designu ~84 marek. Każda w `design-md/<marka>/DESIGN.md` (tokeny, kolory, typografia, komponenty, zasady) + `README.md`.

## Jak używać
1. Wypisz dostępne marki: `ls design-md/` (względem katalogu tego skilla).
2. Dobierz markę pasującą do prośby (np. e-commerce → `shopify`, `stripe`, `nike`, `airbnb`; minimalizm → `apple`, `linear.app`, `vercel`).
3. Przeczytaj `design-md/<marka>/DESIGN.md` i zbuduj UI zgodnie z jej tokenami i regułami. Nie kopiuj logotypów ani znaków towarowych marki.
4. Jeśli użytkownik chce, skopiuj wybrany DESIGN.md do roota projektu jako `DESIGN.md`.
